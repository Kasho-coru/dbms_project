🩸 Smart Blood Bank & Emergency Response Management System
A Database-Driven Platform for Blood Donation, Inventory Management, and Emergency Coordination

A full-stack DBMS project designed to centralize blood donor records, blood bank inventory, hospital information, donations, medical screenings, and emergency blood requests in one web-based management system.

Technology Stack
React

TypeScript

Vite

Tailwind CSS

Supabase

PostgreSQL

SQL


Key Features
- Donor and donation management
- Blood stock and inventory tracking
- Emergency blood requests
- Medical screening and eligibility
- Hospital and blood bank management
- Reports and database operations
